Robot command description

You can send the following commands in the conversation (supports Chinese and English):

  • Help help— Show this help | Show this help
  • List list— List all conversation titles and IDs | List conversations
  • Switch <ID> switch <ID>— Specify conversation to continue | Switch to conversation
  • New conversation new— Start new conversation | Start new conversation
  • Clear clear— Clear the current context | Clear context
  • Current current— Show current conversation ID and title | Show current conversation
  • Stop stop— Interrupt current task | Stop running task
  • Role roles— List all available roles | List roles
  • Role <name> role <name>— Switch current role | Switch role
  • Delete <ID> delete <ID>— Delete the specified conversation | Delete conversation
  • Version version— Display the current version number | Show version

In addition to the above commands, direct input will be sent to AI for penetration testing/security analysis. Otherwise, send any text for AI penetration testing / security analysis.
